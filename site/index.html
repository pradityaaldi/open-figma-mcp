Your AI designs in Figma. You watch it happen.AI mendesain di Figma. Anda menontonnya.

Connect Claude, Cursor, Command Code or any MCP app to the Figma file you have open. It builds on your canvas layer by layer, runs on your own computer, and has no Figma API quota. Setup takes about ten minutes and no coding.

Hubungkan Claude, Cursor, Command Code, atau aplikasi MCP lain ke file Figma yang sedang Anda buka. AI membangun desain di canvas lapis demi lapis, berjalan di komputer Anda sendiri, dan tanpa kuota API Figma. Pemasangan sekitar sepuluh menit, tanpa coding.

Why not Figma's own MCP server?Kenapa tidak pakai MCP server resmi Figma?

Figma offers two official MCP servers. Both are great for turning designs into code. They differ from this project in where they run, what they can write, and how often you can call them. Every official fact below links to Figma's own documentation.

Figma punya dua MCP server resmi. Keduanya bagus untuk mengubah desain menjadi kode. Bedanya dengan project ini ada di tempat berjalan, apa yang bisa ditulis, dan seberapa sering bisa dipanggil. Setiap fakta resmi di bawah bertaut ke dokumentasi Figma.

If something doesn't work.Jika ada yang tidak berjalan.

Do I need to install Node.js myself?Apakah saya harus memasang Node.js sendiri?

No. If Node.js 20 or newer is already installed, the installer uses it. Otherwise it downloads the official LTS build from nodejs.org into ~/.local/share/unofficial-figma-mcp/node, just for this app; uninstalling removes it too. To always use that private copy, even when you have Node.js:

Tidak. Jika Node.js 20 atau lebih baru sudah terpasang, installer memakainya. Jika belum, installer mengunduh build LTS resmi dari nodejs.org ke ~/.local/share/unofficial-figma-mcp/node, khusus untuk aplikasi ini; uninstall ikut menghapusnya. Untuk selalu memakai salinan pribadi itu, meski Anda punya Node.js:

curl -fsSL https://pradityaaldi.github.io/unofficial-figma-mcp/install.sh | bash -s -- --use-bundled-node
The installer says “Figma settings not found”Installer menampilkan “Figma settings not found”

Open Figma Desktop at least once and sign in, then run the installer again. Or register the plugin by hand: in Figma choose Plugins → Development → Import plugin from manifest… and pick the manifest.json path the installer printed.

Buka Figma Desktop minimal sekali dan login, lalu jalankan installer lagi. Atau daftarkan plugin manual: di Figma pilih Plugins → Development → Import plugin from manifest… lalu pilih path manifest.json yang dicetak installer.

The AI says the plugin isn't connectedAI bilang plugin belum terhubung

Run the plugin again in the file you want to work on (step 3). It stops when you close that file or Figma. If it still fails, fully quit and reopen your AI app.

Jalankan lagi plugin di file yang ingin dikerjakan (langkah 3). Plugin berhenti saat file atau Figma ditutup. Jika masih gagal, tutup penuh lalu buka lagi aplikasi AI Anda.

My AI app doesn't show any Figma toolsAplikasi AI tidak menampilkan tool Figma

Check the path in your MCP settings. It must match the one the installer printed exactly and usually ends in /.local/bin/unofficial-figma-mcp. Save, then fully restart the AI app.

Periksa path di pengaturan MCP. Harus sama persis dengan yang dicetak installer dan biasanya berakhir dengan /.local/bin/unofficial-figma-mcp. Simpan, lalu restart penuh aplikasi AI.

Nothing appears when I run the pluginTidak ada yang muncul saat plugin dijalankan

That's expected. The plugin runs in the background without a window. Ask your AI “Is Figma connected?” to confirm.

Itu memang begitu. Plugin berjalan di latar belakang tanpa jendela. Tanyakan ke AI “Apakah Figma sudah terhubung?” untuk memastikan.

Can I use two AI apps at once?Bisa pakai dua aplikasi AI sekaligus?

Yes. The first app to start owns the connection on port 3055 and the others relay through it, so they all share the same Figma plugin.

Bisa. Aplikasi yang pertama jalan memegang koneksi di port 3055 dan yang lain menumpang lewatnya, jadi semuanya berbagi plugin Figma yang sama.

How do I update or uninstall?Bagaimana cara update atau uninstall?

To update, run the install line from step 1 again. To remove the command and the plugin:

Untuk update, jalankan lagi baris instalasi dari langkah 1. Untuk menghapus command dan plugin:

curl -fsSL https://pradityaaldi.github.io/unofficial-figma-mcp/install.sh | bash -s -- --uninstall
Is it safe for important files?Aman untuk file penting?

The server runs locally, but the AI can read and change the open file when you ask it to. Work in a duplicate at first, read what the AI says it will do, and use Figma's version history to roll back.

Server berjalan lokal, tetapi AI bisa membaca dan mengubah file yang terbuka sesuai permintaan Anda. Awali di file duplikat, baca apa yang akan dilakukan AI, dan pakai version history Figma untuk kembali.
