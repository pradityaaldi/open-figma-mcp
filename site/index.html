03

Periksa Node.js

Salin perintah pendek di bawah. Tempel ke Terminal dengan ⌘ + V, lalu tekan Enter.

node --version
Jika muncul v20, v22, v24, atau lebih besar: lanjut ke langkah 4.
Jika muncul “command not found”: unduh Node.js LTS dari situs resminya, buka file installer, klik Continue sampai selesai, lalu tutup dan buka kembali Terminal.

04

Pasang Open Figma MCP

Klik Salin, tempel ke Terminal, kemudian tekan Enter. Tunggu sampai proses selesai; biasanya 1–3 menit.

curl -fsSL https://pradityaaldi.github.io/open-figma-mcp/install.sh | bash

Command ini mengunduh project dari GitHub dan memasangnya hanya untuk akun komputer Anda. Tidak memakai sudo.

Figma mungkin tertutup lalu terbuka kembali satu kali. Ini diperlukan agar plugin bisa didaftarkan. Simpan pekerjaan sebelum menjalankan installer.

05

Simpan konfigurasi yang muncul

Di akhir pemasangan, Terminal menampilkan kotak teks bernama MCP client configuration. Jangan mengetik ulang. Salin seluruh bagian dari kurung kurawal pembuka sampai penutup.

{
  "mcpServers": {
    "open-figma-mcp": {
      "command": "/Users/nama-anda/.local/bin/open-figma-mcp"
    }
  }
}
Penting: path setiap komputer berbeda. Gunakan konfigurasi yang benar-benar muncul di Terminal Anda, bukan contoh di atas.

Masukkan ke aplikasi AI

Cari menu pengaturan MCP pada aplikasi AI Anda. Nama menunya dapat sedikit berbeda antarversi.

CursorSettings → Tools & Integrations → MCP Tools → tambahkan server custom.
Claude DesktopSettings → Extensions atau Developer → tambahkan MCP lokal. Restart aplikasi setelah menyimpan.
Command Code / Claude CodeDi Terminal: cmd mcp add --scope user open-figma-mcp -- PATH (atau claude mcp add dengan format sama). PATH = nilai "command" di atas. Cek dengan /mcp.
Aplikasi lainCari “MCP Servers”, “Tools”, atau “Integrations”, lalu gunakan konfigurasi JSON tadi.
06

Jalankan plugin di file Figma

  1. Kembali ke Figma Desktop dan buka file desain.
  2. Pilih menu Plugins → Development → Open Figma MCP.
  3. Biarkan jendela plugin kecil tetap terbuka selama memakai AI.
Berhasil: titik di jendela plugin berubah menjadi hijau setelah aplikasi AI tersambung.

Bantuan

Jika sesuatu tidak berjalan.

Sebagian besar masalah selesai dengan membuka ulang plugin atau aplikasi AI. Cocokkan pesan yang Anda lihat dengan daftar berikut.

Terminal menampilkan “node: command not found”

Node.js belum terpasang. Buka nodejs.org/en/download, unduh versi LTS, jalankan installernya, lalu tutup dan buka kembali Terminal. Ulangi node --version.

Installer mengatakan “Figma settings not found”

Pastikan Figma Desktop pernah dibuka dan Anda sudah login. Installer akan menampilkan lokasi file manifest.json. Di Figma pilih Plugins → Development → Import plugin from manifest…, lalu pilih file tersebut.

Plugin terbuka tetapi titiknya tidak hijau

Pastikan aplikasi AI sudah direstart setelah konfigurasi MCP disimpan. Tutup lalu buka kembali plugin Open Figma MCP. Pastikan hanya satu aplikasi yang memakai port 3055, kemudian coba minta AI “periksa status Figma”.

Aplikasi AI tidak menampilkan tools Figma

Periksa kembali path pada konfigurasi. Path harus sama persis dengan yang dicetak installer dan biasanya berakhir dengan /.local/bin/open-figma-mcp. Simpan konfigurasi lalu restart aplikasi AI sepenuhnya.

Apakah jendela plugin boleh ditutup?

Jangan ditutup selama Anda ingin AI mengakses Figma. Jendela boleh diperkecil atau dipindahkan. Jika tertutup, jalankan kembali melalui Plugins → Development → Open Figma MCP.

Bagaimana cara update?

Jalankan kembali command instalasi yang sama di Terminal. Installer akan mengambil release terbaru dan mempertahankan nama command yang sama.

Bagaimana cara menghapusnya?

Jalankan: curl -fsSL https://pradityaaldi.github.io/open-figma-mcp/install.sh | bash -s -- --uninstall. Command dan plugin development akan dihapus dari komputer.

Apakah ini aman untuk file penting?

Server berjalan lokal, tetapi tools dapat membaca dan mengubah file Figma yang terbuka sesuai instruksi AI. Gunakan version history Figma, baca konfirmasi tool, dan lakukan percobaan pertama pada duplikat file.

Siap mencoba?

Simpan pekerjaan Figma Anda, buka Terminal, lalu salin command ini. Menjalankan command yang sama di kemudian hari juga akan melakukan update.

curl -fsSL https://pradityaaldi.github.io/open-figma-mcp/install.sh | bash
