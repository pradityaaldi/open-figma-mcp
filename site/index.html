Setup

One command. Three small steps.

01

Run the installer

It downloads the latest release, installs dependencies, and registers the local development plugin.

02

Open the plugin

In a Figma file, choose Plugins → Development → Open Figma MCP and leave its small window open.

03

Connect your client

Copy the MCP configuration printed by the installer. The status dot turns green when your agent connects.

Capabilities

Enough access to actually do the work.

figma_execRun Plugin API JavaScript against the open document.
figma_screenshotExport any node as an inline PNG.
figma_get_metadataInspect the structure, names, types, and sizes.
figma_get_selectionRead what is selected right now.
figma_get_pagesList document pages and their identifiers.
figma_set_pageSwitch the page your agent works on.
figma_statusCheck the bridge, open file, and current page.
figma_toggle_uiShow or hide the plugin window when needed.
